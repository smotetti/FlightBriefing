Import button

Set up once

  1. Tap Copy code below.
  2. In Safari tap Share, then Add Bookmark. Name it Briefing, choose Favorites and save. This only saves this page for now.
  3. Open your bookmarks (the book icon), choose Favorites, tap Edit and tap Briefing. Delete the address and paste the code you copied. Tap Done.

Use it on every flight

  1. Log into the portal and open the flight's Details page.
  2. Tap the address bar and tap Briefing in your Favorites.
  3. Wait a few seconds. The flight briefing page opens with the flight added.
